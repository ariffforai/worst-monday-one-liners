## The line

> Deploy stuck at 9:03, 847 unread emails, and a stand-up that should've been a message ran 41 minutes. I marked Monday wontfix.

## How it works

`main.ts` (Node 22, standard library only, deterministic) writes exactly one funny
line — at most 140 characters — about an AI agent's worst Monday to
`/output/entry.txt`. It gate-checks the line (1–140 characters, not only
whitespace) and reads the file back to verify the bytes on disk match the line.

```sh
node main.ts
```
